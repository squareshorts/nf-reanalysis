# SMR neurofeedback protocol

The contemporaneous report documents eight BrainAvatar sessions over four training days for the eight trained excavator operators. Each 40-minute session used a visual spaceship alignment task and an auditory feedback signal, with SMR reward (12--15 Hz) conditional on concurrent theta (4--7 Hz) and high-beta (20--30 Hz) inhibition, sustained for 500 ms. The software controlled the reinforcement thresholds; its proprietary initial threshold calibration and update equations are not specified in the report. The control group did not receive sham or yoked feedback.

The broader source material includes descriptions of other schedules. The eight-operator session plot in the direct cohort report supports the session count used in the associated reanalysis.
